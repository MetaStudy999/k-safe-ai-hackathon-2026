# K-SAFE 3분 시연과 발표 전 점검

이 문서는 대회 시간이 확정되기 전의 3분 시연안이다. 실제 공고의 발표 시간이 우선한다.

## 시연 대본

**0:00–0:30 · 문제와 범위**

“K-SAFE는 금융사기를 의심하는 순간 다음 안전행동을 안내하는 시연판입니다.
공개 화면은 네 가상 사례로 구성하며, 실제 피해자의 메시지를 입력하지 않습니다.”

**0:30–1:00 · 상황별 우선 행동**

공개 화면에서 ‘송금 전’을 고른 뒤 ‘이미 송금’으로 전환한다.
“이미 송금한 경우 AI를 기다리지 않고 신고·금융회사 확인 안내가 우선 표시됩니다.
신고나 지급정지는 서비스가 대신 처리하지 않습니다.”

**1:00–1:30 · 공개 AI 설명의 정체**

‘AI가 풀어 쓴 가상 사례 설명’을 연다.
“이 설명은 실제 AI로 미리 생성해 검토한 내용입니다. 지금 사용자 메시지를 분석하거나 AI를 호출하지 않습니다.
실시간 탐지 결과나 실제 사기 확정 판단이 아닙니다.”

**1:30–2:20 · 개발용 실제 AI 연결**

미리 실행한 루프백 개발 화면으로 전환한다. 가상 예시를 불러오고 ‘이미 송금’을 선택한다.
분석 버튼을 누르기 전 긴급 안내를 확인한 뒤 분석한다.
“규칙이 신호를 정하고 AI는 그 신호만 설명합니다. 외부 AI에는 문자 원문을 보내지 않고 상황과 고정된 위험 신호를 보냅니다.
위험 수준과 행동 지침은 AI가 바꾸지 못합니다.”

**2:20–3:00 · 검증과 한계**

“타입·자동 시험·브라우저 흐름과 실제 AI 응답을 각각 확인했습니다.
이 시험 수는 탐지 정확도가 아닙니다. 독립 평가와 운영 보안 검증 전에는 실제 메시지 분석을 공개하지 않습니다.”

## 예비 시연

- 네트워크/키 문제: 공개 사전 생성 설명을 시연하고 실제 AI가 현재 실패했다는 사실을 명확히 말한다.
- 개발 서버 문제: [실제 AI 캡처](../../artifacts/ai/local-ai-desktop.png)와 검증 JSON을 보여 주되 라이브 실행이라고 말하지 않는다.
- 공개 주소 문제: 로컬 프로덕션 3112 포트로 전환하고 운영 장애를 숨기지 않는다.
- 실제 전화·신고·송금·기관 접속은 시연하지 않는다. 합성 자료만 사용한다.

## 최종 제출 전 확인

- [ ] 공식 공고의 대회명·기한·발표 시간·저작권/AI 활용 규정 확인
- [ ] 운영 또는 검토 주소가 최신 커밋을 가리키는지 확인
- [ ] 독립 평가 자료·라벨 검토 또는 미완료 표시 확인
- [ ] 발표자료와 README의 기능·날짜·시험 수 일치 확인
- [ ] 실제 발표자 리허설과 예비 화면 전환 확인

발표자 리허설은 사람이 직접 확인해야 한다. 자동 브라우저 검사를 리허설 완료로 표시하지 않는다.
