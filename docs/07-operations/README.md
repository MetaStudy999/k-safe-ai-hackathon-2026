## 시연 시작

이번 구현 폴더는 `~/codyssey/k-safe-ai-mvp-20261102`, 브랜치는 `feat/ai-completion-20261102`다. 기존 작업 폴더는 별도로 보존했다.

```bash
cd ~/codyssey/k-safe-ai-mvp-20261102
nvm use
# 설치·빌드가 필요한 새 환경에서만 실행
npm ci
npm run build
# 터미널 A: API 키 없이 공개 고정 사례
PORT=3112 npm run start
# 터미널 B: 승인된 기존 키 파일의 경로만 전달
PORT=3113 node scripts/with-existing-key.mjs dev /path/to/approved-existing.env
```

두 서버는 `127.0.0.1`에 바인딩한다. 공개판은 `http://127.0.0.1:3112/`, 실제 AI 개발 시연은 `http://127.0.0.1:3113/lab`이다. 브라우저가 다른 기기라면 이 주소가 그 기기의 서버를 뜻하므로 같은 호스트의 브라우저 또는 별도 승인된 접근 경로가 필요하다.

키는 기존 파일에서 실행 환경으로만 전달한다. 키를 명령 인자·터미널·문서·새 환경파일·Git·Vercel에 복사하지 않는다. 사용 후 각 서버 터미널에서 Ctrl+C로 종료한다. 프로세스 종료로 로컬 호출 예산이 초기화되므로 이를 전역 비용 통제로 해석하지 않는다.

## 상태별 대응

| 관측 | 시연 대응 | 판정 |
|---|---|---|
| AI 생성 성공 | 규칙 결과와 보조 설명을 구분해 표시 | 실제 호출 증빙은 별도 기록 |
| disabled/no_signals | AI가 실행되지 않았다는 상태를 그대로 설명 | 모델 장애나 생성 성공으로 표시하지 않음 |
| limited | 기존 규칙 안내와 공개 사전 생성 사례로 전환 | 예산 초기화를 위해 반복 재시작하지 않음 |
| unavailable/invalid | 긴급 행동을 유지하고 보조 설명 미제공 표시 | 원시 SDK 오류·입력·키를 로그로 출력하지 않음 |
| 원격 로그인/403 | 로컬 공개판 또는 녹화로 전환 | 원격 검증 PASS로 바꾸지 않음 |
| 규칙 또는 설명의 내용 오류 | 해당 시연 중단·근거와 영향 범위 검토 | 실제 사기 여부를 확정하거나 자동 조치하지 않음 |

개발 AI 제한은 실행당 24회·동시 1회·8초·재시도 0이다. 상황 enum과 고정 위험 신호도 외부 전송 정보다. 실제 피해자의 원문·개인정보를 시연에 사용하지 않는다.

## 예비 자료와 운영 증거

- 10장 PDF/PPTX와 실제 AI 실행 캡처·JSON을 준비했다. 캡처를 라이브 실행이라고 소개하지 않는다.
- 공개 가상 사례 녹화는 API 키 없이 로컬에서 만든 자동 녹화다. 실제 AI 추론·원격 배포·사람 리허설 증거를 대신하지 않는다.
- 독립 탐지 품질, 실제 대회 규정과 제출, 장기 모니터링·분산 비용/요청 제한은 미완료다.
- 운영 중 개인정보·비밀 노출이 관측되면 관련 실행을 중지하고 비밀이 없는 영향 범위만 기록한다. 키 변경은 해당 키의 다른 사용처를 확인하고 별도 판단한다.
