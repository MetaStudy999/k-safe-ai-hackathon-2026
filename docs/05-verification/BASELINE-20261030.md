## 05-2 수정 지시의 근거

- **위험 누락 감소:** 배송지 오류→링크, 청첩장→링크, 결제 승인→취소·본인확인, 관세 미납→조회 링크·결제의 **복합 문맥**을 감지.
- **오경보 감소:** 단순 '앱 설치', '계정 정지' 등장만으로 경고하지 않고 사용자 행동 **요청** 또는 실제 긴급 **압박**인지 구분.
- **보수적 결과:** 링크가 있다는 사실만으로 악성·불법을 확정하지 않음. 위험이 1개라면 '추가 확인 필요'이며, 실제 URL을 자동 방문하지 않음.
- **회귀 방지:** 기존 정상/위험 9개 단위시험과 이번 6개 실패 사례를 자동시험으로 추가.
- **독립 확인 필요:** 개선된 동일 30개 사례 재시험 후 추가로 **처음 보지 않은 합성 사례**로 과적합 위험을 확인해야 한다.

## 증거 범위 및 주의

이 문서의 수치는 **합성 테스트 세트에 대한 규칙 엔진 평가 결과**이며 **실제 금융사기 탐지율 또는 피해 감소율을 의미하지 않음**. 사람이 지정한 '위험' 범주도 실제 사기 확정 판정이 아니다. 테스트 문구에 맞춘 규칙 보완으로 점수가 상승하더라도 일반화 성능의 증거는 될 수 없다.
