## 구현 범위

| 구분 | 구현과 확인 | 한계 |
|---|---|---|
| 공개 가상 사례 | 네 상황·기존 안전행동·사전 생성 AI 설명 | 사용자 입력·실시간 AI 분석 없음 |

| 외부 전송 | 상황 enum, 서버가 만든 신호 ID·고정 설명만 | 상황과 위험 신호도 외부 전송 정보다 |
| 판정·행동 | 규칙이 정하고 AI 결과로 변경하지 않음 | 사기 확정·안전 보증·자동 신고 없음 |
| 개인정보 | 원문·가림문·사용자 작성 근거를 AI 입력에서 제외 | 브라우저→로컬 서버에서는 입력을 처리함 |

| 비용 통제 | 실행당 최대 24회·동시 1회·8초·재시도 0·출력 1200토큰 | 재시작·다중 프로세스의 총비용 한도가 아님 |
| 운영 공개 | production AI 호출 금지, 기존 분석 API 차단 유지 | WAF HTTP 429 검증과 운영 분석 개방은 별도 |

제공자 `store=false`와 SDK telemetry 비활성화는 제공자의 모든 보관 정책 면제를 의미하지 않는다.

## 발견·수정한 규칙 문제

기존 정규식의 `.`이 줄바꿈을 넘지 않아 공개 가상 사례 중 앱 설치·배송지 링크 문장에서 신호가 누락됐다.
[최초 관측](../../artifacts/ai/multiline-baseline.json)을 보존한 뒤 입력 공백을 정규화했다.
줄바꿈·CRLF·탭·유니코드 공백을 사용한 위험 문장과 정상 교육 문장의 회귀 검사를 추가했다.
이 네 공개 문장은 개발·시연 자료다. 수정 후 일치율을 독립 평가 성능으로 주장하지 않는다.

## ChatGPT 상호 검토

Agent Codyssey를 통해 최종 보고를 전달했고, 실제 저장된 `REPLIED / ANSWERED` 회신을 Codex가 조회·보존했다. [회신 원본](../../artifacts/ai/chatgpt-final-review-reply.json)은 보고 기반으로 시연 MVP의 구현·로컬 검증 범위와 원격 검증·독립 평가·제출 미완료를 구분하도록 요구한다. ChatGPT가 코드나 산출물을 직접 열어 검증했다는 의미는 아니다. 지적한 107/74 검사 수 관계를 위에 해소했고, [후속 회신](../../artifacts/ai/chatgpt-followup-reply.json)도 실제 조회했다. 후속 회신은 해당 보고에 실제 추론 증빙이 재기재되지 않았음을 지적했다. 실제 추론·전체 흐름의 직접 실행 근거는 위 `live-verification.json`과 `browser-verification.json`이며, 단순 모의 테스트나 HTTP 200과 구분한다. 두 회신 모두 원격 코드·화면을 직접 확인한 검증이 아님을 유지한다.

## 재현

```bash
npm ci
npm run typecheck
npm test
npm run build
PORT=3112 npm run start
# 다른 터미널: 승인된 기존 키가 있는 환경파일의 경로만 인자로 전달
PORT=3113 node scripts/with-existing-key.mjs dev /path/to/existing.env
```

키를 새 파일에 복사하지 않는다. `/path/to/existing.env`는 본인의 승인된 로컬 경로다.
`npm run verify:ai`와 `npm run generate:ai-demo`는 실제 API를 호출하므로 기존 `OPENAI_API_KEY` 환경에서만 명시적으로 실행한다.
사전 생성 설명은 자동 재생성하지 않는다. 규칙 입력 해시가 달라지면 테스트가 실패하고 재생성·검토가 필요하다.

## 최종 검토가 필요한 항목

1. 실제 대회 공고·제출 기한·AI 기술 요건. 현재 대회명을 추정하지 않는다.
2. AI 작성 후보 24건의 정답 라벨·개인정보·중복 여부 검토. 이 자료는 탐색용이며 05-6의 별도 사람 작성 기준을 충족하지 않는다. 정식 독립 평가에는 별도 작성자의 새 자료가 필요하다.
3. 발표 문구와 공개 사전 생성 설명의 최종 표현. 실제 분석 서비스로 소개하지 않는다.
4. 실제 사용자 입력 공개가 필요하다면 별도 접근 제어·분산 제한·운영 로그 정책·비용 통제를 검증한다.
