K-SAFE AI 기능 구현 검토 자료입니다. 사용자가 기존 OpenAI 키 재사용을 승인했고 프로젝트 완성을 계속 요청했습니다.

현재 구현:
- 기존 규칙 분석은 유지하고, AI에는 메시지 원문/가림문/사용자가 쓴 근거를 보내지 않습니다.
- AI 입력은 고정된 상황 enum과 서버가 관리하는 신호 ID·고정 설명뿐입니다. 메시지 속 명령이나 연락처는 AI 입력에 들어가지 않습니다.
- AI는 고정 신호의 한국어 설명만 생성합니다. 위험 수준·상황별 행동·긴급 안내는 기존 규칙이 결정하며 AI 출력으로 바꾸지 않습니다.
- 구조화 출력 검증, 신호 ID의 정확한 일치, 길이·링크·위험한 확정 표현 검사 실패 시 규칙 결과로 대체합니다. 이 검사만으로 모든 의미적 오류를 검증했다고 주장하지 않습니다.
- 실제 AI 호출은 development + 명시적 활성화 + 키가 모두 있을 때만 허용합니다. production에서는 AI를 호출하지 않습니다.
- timeout 8초, retry 0, 최대 출력 1200 토큰, 로컬 프로세스당 24회·동시 1회로 제한합니다. 이 한도는 운영 WAF나 전역 비용 제한이 아닙니다.
- 제공자 store=false, SDK telemetry 비활성화. 제공자의 모든 보관 정책이 면제된다고 주장하지 않습니다.
- 공개 UI는 네 가상 사례에 대해 실제 AI로 사전 생성하고 검증한 설명을 보여주는 방식으로 준비 중입니다. 실시간 탐지·분석으로 소개하지 않습니다.
- 현재 타입 검사와 자동 테스트 71개가 통과했고, 실제 연결은 검증 중입니다.
